# IET Agra Sports Club Management System 🏆

A modern, responsive, full-stack web application designed to digitize and streamline athletic operations for the Institute of Engineering & Technology (IET), Agra. The platform bridges students, athletes, coaches, and administrators through a central hub for sports events, dynamic match tracking, and team management.

### Key Features
* 🏃 **Sports & Team Directory:** Detailed profiles for college sports, active rosters, coaches, and student-athletes.
* 📅 **Event Registration Engine:** Automated event registration generating unique student tracking IDs (`IET-XXXXXXXX`).
* ⚽ **Match Center & Live Scores:** Real-time updates for ongoing matches, scores, commentary, and post-game summaries.
* 📊 **Student & Admin Dashboards:** Dedicated student portal for tracked registrations alongside an admin dashboard powered by Chart.js analytics.
* 🏆 **Leaderboards & Achievements:** Performance tracking, position rankings, and filterable tournament award showcases.
* 🖼️ **Interactive Gallery & News:** Categorized media gallery and priority announcement system.

### Tech Stack
* **Backend:** Python 3.10+, Django 4.2, Django ORM
* **Frontend:** HTML5, CSS3, JavaScript (ES6+), Bootstrap 5, FontAwesome
* **Database:** SQLite (Development) / PostgreSQL-ready (Production)
